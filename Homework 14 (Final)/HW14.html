Click away! Press F to randomize all the colors again!

For my project I had the idea to create a program that allows the user to generate their own mosaic/kalodescope-esc piece! Originally I made this project without the movement aspect and quite enjoyed the look, but ended up adding movement to make sure it met the requirements, luckily though I actually really enjoy the effect it gave. If I were to take it further I'd probably add the ability to select certain colors you'd like to be used, and maybe a button to reset, but I figured you could just hit ctrl + r.
